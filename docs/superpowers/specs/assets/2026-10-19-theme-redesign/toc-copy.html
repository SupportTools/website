    Copy buttons on code blocks

    These really copy. Click one, then paste somewhere to see exactly what you'd get. Screen readers hear "Copied" when it works.

    A

    Header bar: language, filename, Copy

    Every block gets a slim top bar showing what it is (bash, YAML, and a filename when there is one) and an always-visible Copy button. Most discoverable.

  name: replica-replenishment-wait-interval

    B

    Corner button, shown on hover

    Cleanest look. The button appears when you hover over or tab into the block, and is always visible on phones. Downside: people who don't hover may never notice it.

    kubectl -n longhorn-system get volumes.longhorn.io \
  -o 'custom-columns=NAME:.metadata.name,STATE:.status.robustness'
    C

    Header bar plus "Copy commands only"

    Same as A, but terminal sessions that show $ prompts and output get a second button that copies only the commands, without prompts or output, ready to paste.

    terminal
    $ kubectl -n longhorn-system get replicas -l longhornvolume=pvc-3f2a
NAME                      STATE     NODE     FAILEDAT
pvc-3f2a-r-1b9c           running   node-a
pvc-3f2a-r-7d41           stopped   node-c   2026-10-12T04:11:09Z
$ kubectl -n longhorn-system patch replica pvc-3f2a-r-7d41 --type merge -p '{"spec":{"rebuildRetryCount":0}}'
replica.longhorn.io/pvc-3f2a-r-7d41 patched

    All three keep the fixes from the color work: AA-contrast syntax colors and a visible keyboard focus ring. Tab to a button to see it.
